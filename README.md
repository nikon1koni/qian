# 电子求签 · 六十四卦

> 心有所问，签自有应。摇一支签，看看这一卦怎么说。

一个单页的电子求签应用。签筒里是六十四支卦签，摇签后浮出一支，展开一张传统签文纸：签等、卦名、卦象、四句签诗，以及推断、大象、运势、爱情、疾病、失物、诉讼分项。界面取道观檐下的暗金、朱砂与旧纸色，不做预测，只做传统文化框架下的签文呈现。

在线求签：**https://nikon1koni.github.io/qian/**

![电子求签界面](preview.jpg)

## 怎么用

1. 静一静，在「所问」里选一个方向，或保持「随缘」。
2. 点「摇签」，签筒响动，一支签浮上来。
3. 看签文；可以复制签文，或点「查看签记」回看历次求签。
4. 想再问一次，点「再求一签」。

## 签文包含

- **签等**：上上、上吉、中吉、中平、下下等（以原始签谱为准）
- **卦名与卦象**：如「震为雷」「地山谦」，含上下卦与六爻符号
- **签诗**：四句传统卦辞
- **推断**：这一签的总断
- **大象 / 运势**：卦象与阶段走势
- **爱情 / 疾病 / 失物 / 诉讼**：分项参考
- 若在「所问」选了方向，对应的分项会高亮

## 签记

求过的签会自动存进浏览器本地（localStorage，最多 12 条），右上角「签记」可以回看、重开或清空。数据只存在你自己的浏览器里，不上传。

## 本地运行

不需要安装依赖，也不联网请求：

```bash
# 直接双击 index.html，或
python -m http.server 8000
```

`index.html` 读取同目录的 `data.js`（`window.QIAN_DATA`，64 条签文数据）。

## 数据说明

签文取自传统《易经》六十四卦签谱，包含签等、卦辞、推断、大象、运势、爱情、疾病、失物、诉讼等条目。签文属于传统文化与娱乐参考，不构成医疗、投资、婚姻或法律建议；遇到现实问题，请以专业意见为准。

## 技术

单文件 HTML/CSS/JS，无框架、无构建；Web Audio 合成摇签与落签音效；CSS 动画完成签筒摇动与签纸展开；`prefers-reduced-motion` 下自动收敛动效。
